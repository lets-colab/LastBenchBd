# Last Bench Parent Brand

This folder is the canonical human + agent entry point for Last Bench identity.

## Start here

- `BRAND_BLUEPRINT.md` — brand architecture, colors, typography and production rules
- `ART_DIRECTION.md` — look, feel, photography, composition, campaign and motion direction
- `STYLE_DNA.md` — approved execution grammar for posters, roll-ups, walls, IDs, web and campaign systems
- `LOGO_USAGE.md` — mandatory transparent adaptive-logo rule
- `brand-lock.json` — machine-readable identity policy
- `logo-full.png` — existing production lockup source
- `logo-icon.png` — production bench + rising-arrow icon
- `logo-lockups.png` — master/reference board
- `reference/` — visual guideline and application boards

## Critical logo rule

**Transparent background always.**

- Light background -> black/charcoal wordmark + green bench-arrow.
- Dark background -> white wordmark + green bench-arrow.
- Never add a black/white logo plate.
- Never ask an image model to recreate the mark.

When a visual reference conflicts with this current rule, this rule wins.
