# CLASS[Λ] — Canonical Brand Blueprint

Status: **canonical capability-brand reference**  
Parent ecosystem: Last Bench  
Implementation namespace: `landing/class-a/`

## 1. Brand definition

**Name:** CLASS[Λ]  
**Role:** Capability accelerator / one-person venture-building engine  
**Current identity line:** **ACQUIRE. APPLY. ADVANCE.**

CLASS[Λ] is designed to move a learner from AI beginner toward a venture-ready founder through practical capability, proof-of-work, systems, prompting, tools, automation and execution.

## 2. Product architecture

### Class 0 / Free Masterclass

A free entry point that introduces the operating model and routes qualified learners into the full program.

### Full program

The current production funnel positions the paid offer as a **20-Class One-Person Venture Builder** with proof-of-work outcomes.

The visual system must support conversion without becoming a generic course-marketing template.

## 3. Core visual DNA

CLASS[Λ] is visually independent from Last Bench parent marketing.

Use:

- near-black cinematic canvas;
- editorial white/off-white typography;
- neutral graphite/silver materials;
- strong negative space;
- technical/grid texture kept extremely subtle;
- controlled depth, perspective and orbital geometry;
- a premium technical/editorial feel.

Do **not** automatically apply Last Bench green/white marketing styling to CLASS[Λ].

## 4. Signature hero system

Current locked direction includes:

- **ONE PERSON. A FULL AI TEAM.**
- **AI BEGINNER → VENTURE-READY FOUNDER**
- dimensional floating **20** object;
- restrained orbital rings;
- cinematic depth and parallax;
- conversion-first CTA.

The floating 20 and orbital system should feel like an AI operating system, not a game UI or decorative gimmick.

## 5. Logo system

Canonical files in this folder:

- `class-a-logo.jpg`
- `class-a-favicon.jpg`
- `last-bench-parent-mark.png` — parent endorsement mark only

Exact fingerprints are stored in `brand-lock.json`.

### Non-negotiable

- Never redraw or regenerate the CLASS[Λ] logo.
- Never approximate the Λ or wordmark using a random font.
- Never replace the source logo with an AI-generated version.
- Keep the Last Bench parent mark separate; do not merge it into a new hybrid logo.

## 6. Typography and hierarchy

The hero typography is the dominant graphic device.

- preserve aggressive scale;
- preserve intentional mobile line breaks;
- keep supporting copy materially quieter;
- do not shrink the hero merely to make layout easier.

If a precise font file is not canonically available, preserve the existing implementation rather than inventing a new brand typeface.

## 7. Motion

Allowed:

- slow physical float;
- subtle orbital movement;
- restrained camera/parallax;
- staggered editorial reveals;
- meaningful CTA state changes.

Avoid:

- bouncy motion;
- neon overload;
- particle-heavy effects;
- playful game-like animation.

Always respect `prefers-reduced-motion`.

## 8. Conversion and truth

The cinematic system must never obscure the offer.

- Free masterclass must stay explicitly free.
- Paid program price/copy must come from current approved production truth.
- Never add dates unless explicitly approved.
- Never manufacture outcomes, testimonials, cohort sizes, revenue or employment claims.

## 9. Production release gate

CLASS[Λ] is not visually approved merely because the build or deployment succeeds.

Required:

1. exact logo asset;
2. visual comparison against the approved cinematic source;
3. mobile and desktop QA;
4. functional form/CTA verification;
5. accessibility and reduced-motion checks;
6. saved/live artifact inspection.

The mandatory visual guardrail remains:

`skills/class-a-visual-source-lock/SKILL.md`
