# Cinematic environment plates

Generated visual artwork, 25 October 2026. These are illustrative cinematic environments, not live footage, campus surveys or evidence of a real office, partner or commissioned project.

- `hub-atrium.webp`: charcoal architectural arrival and three visual apertures.
- `colab-laboratory.webp`: white glass architectural business laboratory.
- `malaysia-city.webp`: Kuala Lumpur-inspired city establishing scene.
- PNG masters for hub/co.lab are retained as source artwork; runtime uses compressed WebP.

The exact Last Bench logo, approved founder portraits and original CLASS silver 20/orbit identity are separate existing assets. Camera enhancement projects these plates into an authored perspective scene; it is not a reconstructed, free-roaming city.
